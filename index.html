배경
Play Console에서 ‘DEX 코드 최적화 기준 미달(난독화 1%)’ 경고 → 난독화 도입 필요
위험

해결

  • @Keep은 코드에만 있어서 이후 구현하는 사람이 실수로 빠뜨릴 수 있다고 판단 → 빌드할 때 위험한 코드를 검사해 빌드를 멈추는 코드(r8-guard.gradle)를 AI에 요청해 추가
결과
8개 프로젝트에 적용, 배포 후 관련 오류 없음 (자세한 과정 보기)

  • 화면비 2.4 이상·1.3 미만 기기(21:9 = 2.33, 4:3 = 1.33 기준 밖)는 특정 아이콘 수치 예외 처리
  • 회전·창 크기 변경 대응 — 화면 방향 portrait → fullUser, 화면 변경 시 앱을 다시 띄우지 않고 크기만 다시 계산, 스크롤 위치·탭 크기 유지, 폴드 접힘·펼침 기준 재계산

결과

배경
회사에서 기본 갤러리 앱처럼 핀치 줌 시 애니메이션 효과를 요청 — 성능 문제와 개발 기간이 늘어날 수 있다고 미리 공유했고, 괜찮다는 답변을 받아 진행

4. 포토북 복잡한 뷰 터치 조작 기능 구현 (찍스 포토북)2020.03 ~ 2020.08
배경
2020 포토북 편집기 리뉴얼(전면 재작성) 과정에서 사진·사진틀·스티커 뷰의 줌, 이동, 뷰 터치 등 터치 관련 동작을 새로 구현
해결
  • ActionEvent를 활용해 사진·포토북·스티커 뷰별 공통 동작을 기준으로 먼저 구현한 뒤, 뷰마다 필요한 기능을 추가로 바꿔 제스처끼리 충돌하지 않도록 구성
  • 스티커를 화면보다 크게 늘릴 수 없던 문제 — 테스트 중 RelativeLayout에서는 뷰 가로 길이가 화면 너비를 넘지 못하는 등 RelativeLayout과 FrameLayout의 동작 차이(API 동작 차이)를 발견, 스티커 부모를 FrameLayout으로 바꾸고 부모 뷰의 잘라내기(clipChildren)를 해제해 해결 (2020.03 발견 → 2020.08 해결)
  • 확대 상태의 터치 처리 — 확대 배율만큼 터치 좌표를 보정하고, 두 손가락 줌이 시작되면 사진 뷰의 길게 누르기·클릭을 끄고 터치를 줌 레이아웃으로 넘겨 줌 인/아웃 중 사진 클릭이 안 되던 오류 수정
  • 겹친 뷰의 터치 충돌 — 편집 화면 뒤쪽 뷰가 눌리는 현상, 투명 화면 안 사진틀이 선택되는 현상, 스티커를 처음 누를 때 삭제·크기 조절 버튼이 같이 눌리는 문제 수정
  • 글자 크기를 많이 줄이면 실제 위치와 어긋나는 문제 — 칸 너비에 맞는 글자 크기를 이분 탐색으로 계산하도록 변경
결과
스티커 크기 조절·회전, 사진 위치 변경, 표지 영역 이동 범위 제한 등 편집 화면 터치 동작 구현 — 2020 포토북 편집기 리뉴얼에 포함
