배경
OpenCV가 일부 기기에서 로딩에 실패하고, Android 16KB 페이지와 호환되지 않고, 앱 용량을 키움. 단계적 축소를 반복하며 대비·채도가 조금씩 변하는 문제도 있었음
해결
OpenCV의 리사이즈 방식을 Kotlin으로 다시 구현하고 1회 축소로 변경 (AI 활용)

결과
OpenCV 결과와 픽셀 차이 0~1 유지, 셀프증명 APK 49.9MB → 36.8MB
3. 셀프증명 코드 최신화 — 바뀐 코드를 익히는 개발자 학습 페이지 제작 (찍스 셀프증명)2026.10
배경
AI를 도입해 셀프증명 코드를 최신화(Java → Kotlin·코루틴 전환, Hilt 의존성 주입 적용)하면서 코드 구조가 크게 바뀜
해결
  • AI 작업은 한 번에 맡기지 않고 에러 수정 → lint → Kotlin 전환 → 코루틴·Hilt 순서로 나눠 진행. 단계마다는 바뀐 부분만 확인하고, Q/A 요청 전 전수 검사 (자세한 과정 보기)
  • 바뀐 코드를 개발자가 읽고 고칠 수 있도록 학습 페이지 2종을 AI에 요청해 제작 — Kotlin 유지보수 교육(10장, 마무리 퀴즈), Hilt 입문
  • 실제 셀프증명 코드(장바구니 주문 업로드 등)를 예제로, 무엇이 바뀌었는지 → 핵심 개념 → 자주 하는 작업 레시피 → 에러·함정 순서로 구성
  • 장마다 ‘이해함’ 체크로 학습 진도를 확인

배경

  • ExifInterface도 성능이 느려 스레드 풀로 여러 사진을 동시에 읽는 병렬 처리 방식으로 변경 (2022.02)
  • 갤럭시 S22·S9, Android 5 기기 등 다양한 기기에서 테스트해 최적의 동시 처리 개수를 스레드 5개로 설정
결과
저사양(Android 5) 기기부터 최신(갤럭시 S22) 기기까지 안정적으로 동작하도록 배포
