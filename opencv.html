OpenCV 제거 — 리사이저 직접 구현과 픽셀 단위 검증

2026.10 · 찍스 셀프증명 등 · AI 코딩 도구 활용 · ㈜디지털포토

배경

  • OpenCV가 일부 기기에서 로딩에 실패
  • Android 16KB 페이지 크기와 호환되지 않음
  • 앱 용량을 키움 (셀프증명 APK 49.9MB)
  • 단계적 축소를 반복하며 대비·채도가 조금씩 변하는 문제

해결

OpenCV의 리사이즈 방식(축소는 면적 평균, 확대는 Lanczos4)을 Kotlin으로 다시 구현하고, 여러 번 나눠 줄이던 것을 1회 축소로 바꿨습니다. 구현은 AI 코딩 도구를 활용했고, 결과가 OpenCV와 같은지는 직접 만든 비교 테스트로 확인했습니다.

검증 방법 — 차이를 검은 화면과 로그로 확인

테스트한 경우 — 기능별로 하나씩

경우확인한 것
큰 이미지 → 작은 이미지축소(면적 평균) 결과가 OpenCV와 같은지
작은 이미지 → 큰 이미지확대(Lanczos4) 결과가 OpenCV와 같은지
PNG (투명 이미지)반투명 가장자리 색이 어두워지지 않는지
줄무늬 셔츠 이미지축소할 때 모아레(줄무늬가 물결처럼 보이는 현상)가 생기지 않는지

테스트 화면은 디버그 빌드에만 넣었고, 결과 이미지와 숫자 요약(summary.txt)을 기기의 Download 폴더에 저장해 PC에서도 다시 볼 수 있게 했습니다.

결과

  • OpenCV 결과와 픽셀 차이 0~1 유지 — 눈으로 구분할 수 없는 수준
  • OpenCV 모듈 삭제로 셀프증명 APK 49.9MB → 36.8MB
