전자책(E-Book) 뷰어 개발 — 북마크 위치 다시 계산

2016 · Android 인턴 (전북대 학점연계) · ㈜우리요

배경

소설 전자책을 읽는 Android 뷰어 앱을 2명이 함께 만들었습니다. 앱에 넣어 둔 책 파일을 읽어, 오픈소스 Pagination 라이브러리로 화면 크기에 맞춰 페이지를 나눴습니다.

구현한 기능

기능내용
책 읽어 오기앱에 넣어 둔 책 파일을 읽어 화면 크기에 맞춰 페이지 나누기
북마크페이지 모서리를 누르면 북마크 생성, 다시 누르면 제거
글자 크기 변경글자 크기에 맞춰 페이지를 다시 나누고 북마크 위치 다시 계산
페이지 이동밀어서 페이지 넘기기 (넘김 애니메이션), 화면을 누르면 메뉴 표시
시크바 · 목록시크바로 원하는 페이지로 이동, 목록 창 열기

문제 — 글자 크기를 바꾸면 북마크 위치가 달라짐

글자를 키우면 한 페이지에 들어가는 글이 줄어 전체 페이지 수가 늘어납니다. 북마크를 페이지 번호로만 저장하면, 글자 크기를 바꾼 뒤에는 같은 번호가 책의 다른 부분을 가리키게 됩니다.

해결 — 페이지 수 변화 비율로 다시 계산

단계계산
① 비율비율 = 바뀐 뒤 전체 페이지 ÷ 바뀌기 전 전체 페이지
② 새 위치새 위치 = 현재 페이지 × 비율
③ 소수점 처리소수점이 0.5 미만이면 버리고, 0.5 이상이면 올림 (반올림)
④ 예외 처리0보다 작으면 0
